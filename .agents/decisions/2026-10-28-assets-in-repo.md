# Theme assets ship in the repo

Decision: the boot and login images (modified Pixabay illustration 7759727, modified Mixkit clip 50745, GPL-3.0 Cross HUD frames, OFL Noto font) are committed so installs need no extra downloads.

Why: the owner wants everything in the repo. Both stock licenses allow modified use inside a larger work and forbid only redistributing the raw original. Every author is credited in CREDITS.md and license texts sit next to the assets.
