# Terminal cheat sheet

## Every day

| Keys / command | Does |
|---|---|
| `Ctrl+R` | search every past command, Enter to reuse |
| `Ctrl+T` | pick a file, pastes its path |
| `Alt+C` | jump into a subfolder |
| `z proj` | jump to a folder you use often (`zi` = pick from a list) |
| `ll` | detailed listing with git status and relative dates |
| `lt` | folder tree, 2 levels |
| `cat file` | file with syntax colors |
| `resume` | pick any past Cursor or Claude chat, from any folder |
| `tldr cmd` | short examples for any command |

## Workspaces (tmux)

| Keys / command | Does |
|---|---|
| `mission` | pick a workspace; `mission name` resumes or creates one |
| `Ctrl+B` then `\|` | split side by side |
| `Ctrl+B` then `-` | split top and bottom |
| `Ctrl+B` then arrows | move between panes (or click) |
| `Ctrl+B` then `d` | detach, everything keeps running |
| `Ctrl+B` then `c` | new window; click its name to switch |

## Tools

| Command | Does |
|---|---|
| `y` | file manager; `q` quits into the folder you were in |
| `lazygit` | git dashboard; `space` stage, `c` commit, `?` help |
| `btop` | system monitor; `q` quits |
| `glow file.md` | read Markdown |

## Recording (labs, OSCP practice)

| Command | Does |
|---|---|
| `asciinema rec box.cast` | start recording; `exit` stops |
| `asciinema play box.cast` | replay; `space` pause, `.` step |
| `asciinema cat box.cast > box.txt` | full text of the session, searchable |

## Fun

`cava` (music), `cava-idle` (waves, no audio), tmux lock screen after 5 idle minutes (6 random animations); preview with `lockscreen NAME` (matrix, pipes, starfield, radar, hex, clock) or `lockscreen` for a random one.
